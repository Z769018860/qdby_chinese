# 战斗回放复盘审阅（唤醒体 / 命轮 / 密契 / 造物），2026-10-15

样本：缓存的 120 场融灾回放（`ids_sub`），每场跑完整 `computeStats` 后检查。共 1942 个命轮/密契/造物条目、480 个唤醒体条目。

## 明确错误

### 1. 密契：触发了却一分不给（最严重）
“触发次数 > 0 且输出/防御/辅助三类全部 < 5 分”的条目共 318 / 1942。命轮只有 1 个，其余全是密契和造物。

| 密契 | 出现 | 零分 | 被漏算的效果（6 件套） |
|---|---|---|---|
| 生机榨取 | 71 | 71 | 回合结束获得银钥能量；血肉界域改为胚胎融合 |
| 入药之梦 | 64 | 64 | 生成卡牌并被打出（生成数已统计，但不进评分） |
| 埋骨地絮语 | 90 | 48 | 触发死亡抵抗后 +50 狂气（效果行里有“狂气 +50”，评分里没有） |
| 再衍化 | 22 | 19 | 开局 35 狂气、每回合 +2 狂气 |
| 无垢启示录 | 14 | 14 | 使用钥令后回复生命 |
| 机械降神 | 16 | 9 | 首回合 +1 算力、首领战每 4 回合 +1 算力 |
| 远方的欢宴 | 6 | 6 | 防御护盾 +60% |
| 海归线 | 3 | 3 | 开局力量 / 深海额外效果 |
| 扭曲双子·黑 | 9 | 3 | 奇数回合置入“打击” |

原因（以 0087b028 为例）：生机榨取的效果行写着“银钥能量 共 4,628（26 次）”“胚胎融合 共 462.8”，但这些银钥能量事件的施放者是各唤醒体，被记到唤醒体名下，密契自己的 `supStore` 为空，所以密契 0 分（D），同时唤醒体的辅助被抬高。
3 件套的纯数值加成（钥令回复 +7.2、狂气回复 +2.4、死亡抵抗 +16.8%、界域精通 +12、暴击率 +4.8% 等）在所有密契里都没有计入。

### 2. 造物：简单的“抽牌 / 算力 / 银钥 / 界域精通”类造物不计分
相同条件下零分的造物：异乡邮票夹+（13/13）、弥萨格徽章（含+，11/11）、银白差分机+（7/8）、日月轮盘+（4/10）、蒙尘缝纫机+、群星之酒+、桂叶袖扣+、定向罗盘（+）、万花筒+、崭新的钱包+、妙手空空+ 等。
例：定向罗盘+（回合开始抽牌）在 1c0db085 触发 19 次，`relicEngine` 无条目，`supStore` 为空，效果类型只被标成 `nominal`，得分 0。

### 3. 被动类条目显示“触发 0 次”却有数值
荒原狼（19 次）、苦咒缚、不灭的饥骨、伏于夜色、信息就是生命等：“触发 0”，但估算贡献很大（荒原狼 07e1fcda 为 116 万）。这类是常驻加成，没有触发事件，界面写“触发 0”会误导。

### 4. 银钥能量归属缺口
4 / 120 场里，回放里的银钥能量总量与计入各来源的总量差超过 40%：07e1fcda（8292 对 3913）、164c42d6（2652 对 1551）、35a46f14（3707 对 690）、0d70e618（5227 对 3101）。35a46f14 里守密人在行动阶段产生了 2679 的银钥能量，没有归到任何来源。

## 需要留意但不算明确错误
- 30 / 120 场里，所有唤醒体伤害之和比队伍总伤害低 15% 以上，差额记在守密人 / 密契 / 造物名下。触腕伤害在统计包里按“提高的触腕数值”分给唤醒体，所以希莱斯特这类的“统计包伤害”和命中记录伤害不一致，属于口径差异。
- 命轮：只有“未送出的花”1 次零分，整体没有发现系统性问题；个别命轮占队伍伤害超过 50%（愿世界化作芬芳 68%、冰川下的沉眠 56%）仅出现各 1 次，没有核对是否合理。
- 唤醒体：没有 NaN / 无穷值，没有“无输出无辅助”的条目，等级分布合理（S 19 / A 37 / B 28 / C 46 / D 30，样本 160）。

## 没有做的检查
- 没有逐个核对 3 件套数值加成的计算方法。
- 没有核对每个造物的描述是否都被建模，只看了“触发了但零分”的这一类。
