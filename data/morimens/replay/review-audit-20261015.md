# 战斗回放复盘审阅（唤醒体 / 命轮 / 密契 / 造物），2026-10-15

样本：缓存的 120 场融灾回放（`ids_sub`），每场跑完整 `computeStats` 后检查。共 1942 个命轮/密契/造物条目、480 个唤醒体条目。

## 明确错误

### 1. 密契：触发了却一分不给（最严重）
“触发次数 > 0 且输出/防御/辅助三类全部 < 5 分”的条目共 318 / 1942。命轮只有 1 个，其余全是密契和造物。

| 密契 | 出现 | 零分 | 被漏算的效果（6 件套） |
|---|---|---|---|
| 生机榨取 | 71 | 71 | 回合结束获得银钥能量；血肉界域改为胚胎融合 |
| 入药之梦 | 64 | 64 | 生成卡牌并被打出（生成数已统计，但不进评分） |
| 埋骨地絮语 | 90 | 48 | 触发死亡抵抗后 +50 狂气（效果行里有“狂气 +50”，评分里没有） |
| 再衍化 | 22 | 19 | 开局 35 狂气、每回合 +2 狂气 |
| 无垢启示录 | 14 | 14 | 使用钥令后回复生命 |
| 机械降神 | 16 | 9 | 首回合 +1 算力、首领战每 4 回合 +1 算力 |
| 远方的欢宴 | 6 | 6 | 防御护盾 +60% |
| 海归线 | 3 | 3 | 开局力量 / 深海额外效果 |
| 扭曲双子·黑 | 9 | 3 | 奇数回合置入“打击” |

原因（以 0087b028 为例）：生机榨取的效果行写着“银钥能量 共 4,628（26 次）”“胚胎融合 共 462.8”，但这些银钥能量事件的施放者是各唤醒体，被记到唤醒体名下，密契自己的 `supStore` 为空，所以密契 0 分（D），同时唤醒体的辅助被抬高。
3 件套的纯数值加成（钥令回复 +7.2、狂气回复 +2.4、死亡抵抗 +16.8%、界域精通 +12、暴击率 +4.8% 等）在所有密契里都没有计入。

### 2. 造物：简单的“抽牌 / 算力 / 银钥 / 界域精通”类造物不计分
相同条件下零分的造物：异乡邮票夹+（13/13）、弥萨格徽章（含+，11/11）、银白差分机+（7/8）、日月轮盘+（4/10）、蒙尘缝纫机+、群星之酒+、桂叶袖扣+、定向罗盘（+）、万花筒+、崭新的钱包+、妙手空空+ 等。
例：定向罗盘+（回合开始抽牌）在 1c0db085 触发 19 次，`relicEngine` 无条目，`supStore` 为空，效果类型只被标成 `nominal`，得分 0。

### 3. 被动类条目显示“触发 0 次”却有数值
荒原狼（19 次）、苦咒缚、不灭的饥骨、伏于夜色、信息就是生命等：“触发 0”，但估算贡献很大（荒原狼 07e1fcda 为 116 万）。这类是常驻加成，没有触发事件，界面写“触发 0”会误导。

### 4. 银钥能量归属缺口
4 / 120 场里，回放里的银钥能量总量与计入各来源的总量差超过 40%：07e1fcda（8292 对 3913）、164c42d6（2652 对 1551）、35a46f14（3707 对 690）、0d70e618（5227 对 3101）。35a46f14 里守密人在行动阶段产生了 2679 的银钥能量，没有归到任何来源。

## 需要留意但不算明确错误
- 30 / 120 场里，所有唤醒体伤害之和比队伍总伤害低 15% 以上，差额记在守密人 / 密契 / 造物名下。触腕伤害在统计包里按“提高的触腕数值”分给唤醒体，所以希莱斯特这类的“统计包伤害”和命中记录伤害不一致，属于口径差异。
- 命轮：只有“未送出的花”1 次零分，整体没有发现系统性问题；个别命轮占队伍伤害超过 50%（愿世界化作芬芳 68%、冰川下的沉眠 56%）仅出现各 1 次，没有核对是否合理。
- 唤醒体：没有 NaN / 无穷值，没有“无输出无辅助”的条目，等级分布合理（S 19 / A 37 / B 28 / C 46 / D 30，样本 160）。

## 没有做的检查
- 没有逐个核对 3 件套数值加成的计算方法。
- 没有核对每个造物的描述是否都被建模，只看了“触发了但零分”的这一类。

## 修复后复测（同一批 120 场）
- “触发了却三类全为零分”的条目从 318 降到 44；生机榨取、入药之梦、埋骨地絮语、再衍化、机械降神、扭曲双子·黑、异乡邮票夹+、弥萨格徽章（+）、日月轮盘+、蒙尘缝纫机+、群星之酒+、桂叶袖扣+、定向罗盘等已全部不再零分。
- 唤醒体评分平均变化 −0.09，480 个唤醒体里只有 3 个变化 ≥ 8 分。
- 剩余的零分多为条件没有达成（银白差分机+ 一回合没有释放够 4 次狂气爆发）或效果本身很小（无垢启示录）；远方的欢宴（防御护盾 +60%）、妙手空空+（开局削弱敌方力量）、Sparganum+ 等仍没有建模。

## 追加排查（2026-10-16）：唤醒体 / 命轮 / 密契 / 造物
- 增益归因溢出：同一次命中被多个“最终伤害 / 力量”类增益同时归因时，各增益份额之和可超过这次命中本身（茉夏的增益额 15.97M > 全队伤害 7.36M）。现按“一次命中的增益份额合计 ≤ 95%”等比缩放，茉夏降为 3.32M。
- 辅助分数：辅助是 12 个互不相关的子项的加权平均，纯增益 / 抽牌 / 算力型唤醒体只在 1 项突出，其余为 0，被平均到 15–35 分（希洛均分 23）。改为 0.7×加权平均 + 0.3×最强三项（0.7/0.2/0.1）；120 场样本平均 +3.6，S 46→63，D 83→42。
- 造物 / 密契：描述为空的合成造物记录（故人的怀表+）改取带描述的状态；固定银钥能量的密契（猩红之拥）按金额 + 持有者认领事件；银钥归属缺口 4 场已补齐；一条指令含多行同类效果时记录总量只计一次（快乐魔法秀银钥 6 万 → 5500）。

## 追加排查 2（2026-10-16）：固伤 / 命轮效果 / 唤醒体
- 固定伤害：回放伤害事件自带 `damageType`（1 主动、3 被动状态可暴击；2 持续伤害（中毒 / 反击类）、6 固定伤害不会暴击），对 120 场逐类核对：`damageType 2 / 6` 共 2000+ 次命中暴击 0 次。已把这两类命中从暴击期望 / 不幸判断 / 暴击溢出 / 暴击率增益估值中排除；原有“伤害指令全是固定 / 真实伤害”的技能判定保留。涉及：莫丝「涡！流！弹！」、庞托斯「猎杀之魇 / 无休猎宴」、卡拉布「粉雪魔咒」，以及徐「夜雾下的情誓」的中毒结算。
- 命轮：对 127 个出场命轮逐个比对“描述 → 已计入的效果”。系统性缺口是“探索开始后把专属卡放入牌库”的命轮（樱花下的迷思、倒数时刻、私密午歇时间、梦游仙境、向上坠落、魂灵同调、青石王座…）：这些卡的打出效果（银钥 / 算力 / 抽牌 / 增益）原先记在打出它的唤醒体名下，命轮只有固定估值。现按描述里「将…「卡名」加入牌库」认领，这些卡打出时产生的银钥、算力、抽牌归命轮（樱花下的迷思 52→72，倒数时刻 54→71）。
- 唤醒体：伤害 / 辅助数值无新增系统性错误（样本评分平均变化 −0.02，最大 4 分）。已知遗留：36a2fe3e 的银钥来源合计比回放事件总量多约 24%（极夜与破晓 / 慈悲的哺育 等按触发次数估值与事件归因重复），其余 119 场在 ±10% 内。
- 误报复核（命轮描述关键词）：改用“获得 / 抽 / 降低”等动词短句 + 已计入项逐类比对（银钥、狂气、算力、减费、抽牌、临时力量、护盾、治疗、暴击），127 个命轮里真正缺口集中在两类：专属卡打出效果（已归命轮）和命轮自身给出的临时力量 / 暴击类增益——后者在命轮触发的同一时刻发生时，原先因为“增益估值只认唤醒体来源”而没有任何人记账，现在记到命轮名下（骑士之心、纯银的初心、日服沙耶专武、伪造的冠冕等）。其余命中的关键词（如“狂气爆发造成的…提高”）是对已有数值的加成而不是产出，不属于缺口。
- 未处理的真缺口：极夜与破晓“使用应急灵知体后算力上限 +3 / 每回合抽牌 +3”（需要识别该钥令的触发）、往昔的花与诗 / 巨人之刃 / 迷失的道路的“费用 -1”（概率或卡牌选择，无法从事件精确还原）。
- 银钥来源合计：按命轮通道总量抬高银钥时，现在以回放里银钥获得事件的总量封顶，超出部分按抬高量等比回退（36a2fe3e：19582 → 15801，与回放一致）；120 场不再有来源合计超过回放总量 5% 以上的回放。
- 极夜与破晓“使用应急灵知体后算力上限 +3 / 每回合抽牌 +3”：在 22 场带该命轮的回放里，没有任何一场出现对应的最大算力 / 抽牌上限变化事件，说明该效果这批回放里都没有触发，不是遗漏；保持不计。
- 往昔的花与诗 / 迷失的道路 / 巨人之刃的“费用 -1”：费用降低是卡牌状态，没有属性事件可统计，改按命轮文字 + 实际触发次数估算（战斗开始抽牌与降费，含死亡抵抗后重复；主动伤害回合数 × 概率；狂气爆发次数 × 概率 × 约 2 张手牌）。

## 反馈场次复核（2026-10-17）：06928b48 / b76f871c
- 来源：回放页“这场有问题”按钮收到的两条反馈（均无文字说明），逐项核对了唤醒体、命轮、密契、造物与守密人评分。
- 发现：造物（relic）一直没有走命轮 / 密契使用的“语义 + 实测”评分，只用团队内相对排名。结果是造成大量增益的造物也被压得很低：b76f871c 的视力矫正器+（每回合前五次伤害 +30%，估算贡献 6.48M ≈ 全队伤害 21%）只有 12 分，哭泣烟斗+（估算贡献 19 万，06928b48 里是全队最高的造物之一）只有 50 分。120 场样本里造物 81% 是 D 级、均分 21。
- 修复：造物接入同一套评分（输出 / 防御 / 辅助取实测与文字语义的较高者）。120 场造物均分 21 → 52（B 339 / A 170 / C 135 / D 126 / S 42），唤醒体评分不变。
- 其余核对无异常：两场的伤害合计与全队伤害一致（b76f871c 99.6%），银钥来源合计与事件一致，幸运提示、死亡抵抗与守密人评分均符合规则。
- 遗留：回放里没有命轮叠位等级，开局头部的命轮“+12 / 3叠”只在该场能在榜单数据里查到时才显示，这两场查不到所以不显示叠位。
