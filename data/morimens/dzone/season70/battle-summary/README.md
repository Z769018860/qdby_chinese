# Season 70 Top2000 Battle Summary

Updated: 2026-10-01 05:00

This directory stores split battle summary JSONL shards extracted from the Top2000 dataset.

Preserved fields:
- bossBattleRoundCount
- deathResistCount
- totalUseCard
- totalEnergyCost
- maxCounterAtt
- maxTentacleDamage
- maxBoutDamage
- battleUuid

The shard files are split to keep repository files within GitHub size limits.
