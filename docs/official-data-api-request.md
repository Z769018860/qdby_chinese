# 忘忘看报：向官方申请的数据 / API 需求清单

> 站点：qingdengbuyi.top/morimens-tools.html（社区非商业工具站，B 站 @青灯不弈）
> 现状：目前的数据靠手动抓取 + 社区整理，官方接口一旦变动就会中断。下面按优先级列出希望官方提供的只读数据。

## P0 必需（融灾榜单）

| # | 需求 | 现在的做法 | 希望官方提供 |
|---|---|---|---|
| 1 | 融灾榜单总参与人数 | 抓到的排行榜只有 Top 2000 行，没有总数字段，只能靠玩家口述 | 每期榜单返回 `totalParticipants`（在榜总人数）及 `snapshotTime`、`isFinal`（赛季结算后的终榜标记） |
| 2 | 榜单分页读取 | 只取 Top 2000 | 支持分页读完整榜（或至少 Top 5000）：名次、UID、昵称、总分、各禁区得分 |
| 3 | 玩家队伍详情（只读） | 逐个 UID 抓取，量大且易失败 | 按 UID（或批量）返回各禁区「通关队 + 额外队」：唤醒体、等级、启灵（potency）、突破、命轮、密契件数、钥令、造物，以及战斗统计（回合数、首领战回合、死扛次数、出牌数、耗能、各唤醒体伤害/格挡/治疗） |
| 4 | 计分与难度规则 | 靠数据反推（▼ 通关分有 90 / 95 两档，原因不明） | 文档说明：每个禁区各难度的基础分、额外队伍加分、满分 525 的构成 |
| 5 | 期次元数据 | 手动维护 | 稳定的赛季 ID、期号、名称、起止时间、戒指界域、禁区 ID 与难度档位 |

## 接口形式（所有数据通用）

- 只读、公开或申请密钥均可；返回 JSON，字段带版本号（`schemaVersion`）。
- 支持 `ETag` / `Last-Modified` 与按期次增量；最好附带更新日志或 Webhook。
- 允许跨域读取（CORS），或提供每日整包下载。
- 时间统一为北京时间（UTC+8）并带时区；未发布内容不提前暴露（可设发布时间）。
- 明确使用条款：本站非商业、署名来源，并按官方要求限频。
