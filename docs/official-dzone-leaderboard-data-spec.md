# 融灾榜单：统计内容与所需数据字段清单

> 给官方的说明：左边是「本站现在汇总统计的内容」，右边是「每项统计需要的原始字段」。
> 状态：✅ 现在能拿到（需手动抓取）　⚠️ 只能推断/不稳定　❌ 拿不到，需要官方提供

## 一、现在汇总的统计内容

| 栏目 | 统计内容 |
|---|---|
| 出场率榜 | 唤醒体 / 命轮 / 密契 / 造物 / 钥令 的出场率；可按 期次、禁区、难度、通关队/额外队、榜单名次范围（Top50/200/500/1000/2000）、总分、启灵档位、等级、是否借用助战、界域、定位 筛选 |
| 配队检索 | 按「包含 / 不含」某唤醒体、命轮、密契搜索队伍并展示详情 |
| 启灵统计 | 各唤醒体在各难度下的 0～2启 / 3启～+3 / +4～+11 / +12 占比 |
| 战斗数据榜 | 平均死扛、平均回合数、单回合最高伤害；角色榜与玩家榜；分布热力图 |
| 玩家详情 | 每名玩家各禁区的队伍、得分、战斗数据 |
| 分数统计 | 各分数档人数（525 / 500 / 450 …）、名次分数线、总参与人数占比 |
| 特刊报告 | 各禁区 ▼ 配队榜、数据之最（伤害/回合/死扛/出牌）、冷门与神秘配队、平均死扛榜、启灵榜 |
| 社区校验 | 社区上传的队伍与官方数据逐场核对 |
| 跨期对比 | 同一唤醒体 / 配队在不同期次的变化 |

## 二、所需字段（按层级）

### 1. 期次（season）

| 字段 | 用途 | 现状 |
|---|---|---|
| seasonId / 期号 / 名称 / 起止时间 | 期次选择、时间轴 | ⚠️ 手动维护 |
| ringRealm（戒指界域） | 本期标签、界域筛选 | ⚠️ 手动维护 |
| stageGroupIds 与 禁区序号对应 | 分禁区统计 | ✅ |
| 难度档位定义（C/B/A/S/SS/SSS/▼）与各禁区各档基础分 | 难度筛选、分数统计 | ❌ 靠反推 |
| 额外队伍加分、满分构成 | 解释 525 分、分数分布 | ❌ 靠反推（▼ 通关分有 90/95 两档，原因不明） |
| 快照时间、isFinal（赛季结算后的终榜） | 更新时间、终榜标记 | ⚠️ 取决于抓取时间 |

### 2. 榜单行（rank row）

| 字段 | 用途 | 现状 |
|---|---|---|
| **totalParticipants（本期总参与/在榜人数）** | 「前 X%」「满分占比」 | ❌ **缺失** |
| rank / uid / 昵称 / 总分 | 排名展示、分数线 | ✅（仅 Top 2000） |
| 并列名次规则 | 同分排名 | ⚠️ 推断 |
| 各禁区得分 + 通关队/额外队的战斗 ID | 分禁区得分 | ✅ |
| 榜单分页（Top 2000 之后） | 全量分布、人数统计 | ❌ 缺失 |
| 玩家等级 / 头像框（可选） | 玩家详情展示 | ⚠️ |

### 3. 队伍（每名玩家 × 每禁区 × 通关队/额外队）

| 字段 | 用途 | 现状 |
|---|---|---|
| 难度（该队伍通关的威胁等级） | 难度筛选、▼ / SSS 统计 | ⚠️ 需由关卡 ID 推断 |
| stageTid / 战斗唯一 ID（battleUuid） | 与战斗统计、社区上传对账 | ✅ |
| 钥令（keeperSkill ID） | 钥令出场率 | ✅（缺新钥令的名称） |
| 造物列表（relics ID，含品质/强化标记） | 造物出场率 | ✅ |

### 4. 唤醒体（每队 4 人）

| 字段 | 用途 | 现状 |
|---|---|---|
| tid / 等级 / 突破 / 等级上限 | 等级筛选 | ✅ |
| potencyLevel（启灵） | 启灵档位、+12 占比 | ✅ |
| 命轮（ID、等级、槽位） | 命轮出场率 | ✅ |
| 密契（套装 ID、件数）、饰品属性 | 密契出场率、件数筛选 | ✅ |
| 天赋 / 属性面板（攻击、暴击等） | 面板对比 | ✅ |
| 是否借用助战 / 助战玩家 | 借用统计 | ✅ |

### 5. 战斗统计（每场战斗）

| 字段 | 用途 | 现状 |
|---|---|---|
| 总回合数、首领战回合数 | 平均回合、最快通关榜 | ✅ |
| 死扛次数 | 平均死扛榜 | ✅ |
| 出牌总数、单回合最多出牌、总耗能 | 数据之最 | ✅ |
| 各唤醒体 伤害 / 格挡 / 治疗 | 单角色最高伤害 | ✅ |
| 单回合最高伤害、最高反击 / 触手 / 力量 / 毒 | 数据之最 | ✅ |
| 最终剩余生命、复活次数 | 险胜榜 | ✅ |
| 每回合行动日志（可选） | 战斗回放复盘 | ❌ |

### 6. 名称与资料（让 ID 变成名字）

| 字段 | 用途 | 现状 |
|---|---|---|
| 唤醒体 / 命轮 / 密契 / 造物 / 钥令 的 ID ↔ 中英文名 | 所有榜单显示 | ⚠️ 新内容常缺中文名（本期 15 个钥令无官方译名） |
| 关卡 ID ↔ 禁区序号 / 难度 | 分禁区、分难度 | ⚠️ 手动对应 |

## 三、缺口汇总（最希望官方补的）

1. **本期总参与人数**（榜单接口返回）。
2. **榜单分页**，读到 Top 2000 之后（用于全量分数分布）。
3. **计分规则说明**：难度基础分、额外队伍加分、满分构成。
4. **按 UID 批量查询队伍详情**的只读接口（现在逐个抓取，量大易失败）。
5. **名称映射表**（ID ↔ 中英文名），新内容随版本同步，尤其是钥令、造物。
6. **赛季终榜标记与快照时间**。

## 四、接口形态示例

```
GET /dzone/seasons                         → 期次列表与元数据（含 totalParticipants、snapshotTime、isFinal）
GET /dzone/seasons/{id}/ranking?page=1     → 分页榜单行：rank, uid, name, score, stageScores[]
GET /dzone/seasons/{id}/players/{uid}      → 玩家各禁区队伍：clear/extra 队伍、唤醒体、命轮、密契、钥令、造物、战斗统计
GET /dzone/seasons/{id}/rules              → 难度档位、基础分、额外队加分
GET /meta/names?type=awakener|wheel|covenant|relic|keytoken&lang=zh-CN,en  → ID ↔ 名称
```

约定：只读 JSON、带 `schemaVersion`、支持 `ETag`、时间统一北京时间、允许跨域、注明使用条款与限频。
